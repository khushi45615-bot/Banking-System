Bank Management System :
A console-based java application that demonstrates core object-oriented programming(OOP) 
principles through the management of customer accounts and
banking operations.

Features :
. Manage customer accounts
. Support saving and current accounts
. Deposit, withdraw, and transfer funds
. Check account balances and review transaction records
. Navigate the application through a menu-driven console interface

Technologies :
.java
.Object-oriented programming(OOP)
.ArrayList
.Java Collections Framework

Project Structure :
. Main.java- Start the application
. Customer.java- Stores customer information
. Account.java- Defines the base account class
. Saving.java- Implements saving account functionality
. CurrentAccount.java- Implements current account functionality
. Transaction.java- Represents transaction details
. Bank.java- Manages banking operations

How to Run :
1. Clone the repository
2. Open the project in java-compatible IDE
3. Compile and run Main.java
4. Follow the instructions displayed in the console

Learning Outcome :
Develop practical experience with java object-oriented programming, inheritance, collections, 
and fundamental banking operations.
